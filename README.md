# Рекомендательный сервис

## Локальный запуск

- Установите зависимости проекта.
- Перед запуском задайте `STARTML_DATABASE_URL` в окружении. Не сохраняйте URL
  подключения и пароли в исходном коде или Git.
- Файл модели `model.pkl` хранится отдельно и намеренно исключён из Git.
  Перед запуском положите модель рядом с `app.py` или задайте `MODEL_PATH`
  для LMS-окружения.

Ноутбук `ModelRebuild.ipynb` содержит код подготовки и сохранения модели.
